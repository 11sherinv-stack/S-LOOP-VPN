# S LOOP VPN — GitHub Pages Starter

این مخزن نسخهٔ وبِ قابل انتشار S LOOP VPN است. می‌توانی فایل‌های همین پوشه را در ریشهٔ یک مخزن GitHub بارگذاری کنی.

## انتشار در GitHub Pages
1. یک مخزن جدید در GitHub بساز.
2. فایل‌های این پوشه (`index.html`، `manifest.webmanifest`، `sw.js`، `icon-192.png` و `icon-512.png`) را در ریشهٔ مخزن بارگذاری کن.
3. در مخزن وارد **Settings → Pages** شو.
4. در بخش **Build and deployment**، گزینهٔ **Deploy from a branch** را انتخاب کن.
5. شاخهٔ `main` و پوشهٔ `/(root)` را انتخاب و ذخیره کن.
6. پس از انتشار، نشانی GitHub Pages مخزن را باز کن.

## نصب روی اندروید
پس از انتشار، سایت را با Chrome باز کن و از منوی مرورگر گزینهٔ **Add to Home screen / نصب برنامه** را بزن (اگر نمایش داده شد).

## وضعیت فنی مهم
- این نسخه یک وب‌اپ/PWA آزمایشی است؛ به‌تنهایی تونل VPN ایجاد نمی‌کند.
- بخش V2Ray فقط لینک کانفیگ را در حافظهٔ محلی مرورگر ذخیره می‌کند؛ موتور V2Ray/Xray و سرویس VPN اندروید در این پروژه وجود ندارد.
- کشورهای آمریکا، آلمان و هلند فعلاً گزینه‌های نمایشی هستند و سرور فعال ندارند.
- برای اتصال واقعی باید بعداً یک سرور مجاز، کانفیگ معتبر و اپ اندرویدی بومی با پیاده‌سازی امن `VpnService` و هستهٔ سازگار اضافه شود.
- کانفیگ‌های خصوصی را در GitHub یا مخزن عمومی قرار نده؛ آن‌ها ممکن است حاوی اطلاعات محرمانه باشند.

## فایل‌ها
- `index.html` — رابط اصلی
- `manifest.webmanifest` — مشخصات نصب وب‌اپ
- `sw.js` — کش فایل‌های اصلی برای بازشدن آفلاین
- `icon-192.png` و `icon-512.png` — آیکن رسمی برنامه (تصویر ارسالی پروژه)
- `icon.svg` — آیکن برداری قدیمی/جایگزین
